# 00. Обзор сервиса

## 1. Назначение

`assistant-service` — LLM-воркер проекта Query Point. Он не предоставляет HTTP API и не содержит frontend-логики. Сервис работает как consumer RabbitMQ и реализует интеллектуальный слой базы знаний:

1. принимает запрос пользователя;
2. определяет намерение;
3. ищет релевантные фрагменты в Elasticsearch в рамках пользователя;
4. готовит ограниченный контекст;
5. формирует grounded-ответ или детерминированный ответ;
6. при необходимости готовит краткое изложение выбранного PDF;
7. публикует progress-события и один итоговый ответ.

## 2. Границы ответственности

### Сервис отвечает за

- строгую валидацию входящих RabbitMQ-сообщений;
- внутреннюю классификацию намерения пользователя;
- tenant-safe retrieval и metadata lookup в Elasticsearch;
- Redis-кэш результатов retrieval и служебного состояния;
- вызовы Gemini с локальными лимитами, retry и безопасными fallback;
- получение PDF из MinIO для full-document summary;
- безопасные логи и контролируемые ошибки;
- unit, contract и opt-in integration tests.

### Сервис не отвечает за

- аутентификацию пользователя в UI;
- HTTP/WebSocket API;
- загрузку файлов пользователем;
- создание Elasticsearch index/mapping;
- извлечение текста и индексирование chunks на стороне Backend;
- хранение исходных документов вне собственного чтения MinIO для PDF-summary.

## 3. Основные пользовательские сценарии

| Сценарий | Внутренний task type | Gemini | Результат |
|---|---|---:|---|
| Вопрос по материалам | `answer_question` | да | grounded-ответ по найденным chunks |
| Объяснение темы | `explain_topic` | да | учебное объяснение только по найденному контексту |
| Поиск документа | `document_search` | нет | детерминированный список найденных фрагментов |
| Краткое изложение PDF | `summarize_document` | да | summary полного выбранного PDF через Files API |
| Неподдерживаемый запрос | `unsupported` | нет | нейтральный fallback |

## 4. Принцип grounded generation

Gemini не вызывается для обычного ответа, пока не выполнены все условия:

- intent требует retrieval;
- есть непустые keywords;
- Elasticsearch вернул подходящие chunks;
- `ContextAgent` сформировал статус `FOUND`;
- контекст не превысил настроенные лимиты;
- итоговый generation prompt укладывается в budget.

Таким образом модель не должна отвечать на основе внешних знаний, памяти модели или текста, которого нет в доступном контексте.

## 5. Ключевые ограничения текущей версии

- Full-document summary поддерживается только для PDF.
- DOCX summary не реализован.
- Vector search не реализован: используется текстовый `match` по полю `text`.
- Пустой retrieval не кэшируется.
- Live Gemini integration tests намеренно не запускаются в pytest, чтобы не расходовать quota.
- Нельзя считать, что worker поддерживает streaming наружу: Gemini stream собирается внутри, а наружу отправляется один финальный `response`.
